# MacDock 版本记录

## 1.9.9.4

- **系统性优化抽屉自动收起与关联交互**：
  - 将抽屉外交互从单一“MenuOpen 开关 + 二元失焦关闭”升级为完整的关联上下文状态机：统一识别 Dock、设置页、独立弹窗、WPF `ContextMenu`（含跨菜单切换防抖）、系统外壳原生菜单（在执行非启动命令前捕获即将弹出的 `#32770` 属性页、`OperationStatusWindow` 与 `"打开方式…"`）及文本输入期 IME 候选窗。
  - 修复右键属性页或 `Alt+Enter` 查看属性、重命名弹窗、设置页及关闭运行中应用等场景下的抽屉误收起问题；同时为被捕获的非置顶属性页协调 Z-Order 并于关闭后恢复普通窗口层级，避免半透明置顶抽屉遮挡属性页，且关闭属性页后（包括抽屉带 `WS_EX_TOOLWINDOW` 的焦点回落情形）正确恢复抽屉与网格焦点（`"打开方式…"` 启动外部应用时除外，不抢占新应用焦点）。
  - 保留点外部、启动应用、`在资源管理器中显示`、三级 `Esc`、Dock 网关点击与切换至无关窗口时的自然即时收起体验，并修正减少动画下的双击防穿透、`ShellCapturePending` 超时清理、键盘切换搜索框 IME 状态同步以及收起中途打断恢复等边界问题。

## 1.9.9.3

- **统一抽屉图标网格**：取消抽屉底部的「手动添加 · 快捷入口」独立分组，手动添加的应用与快捷方式直接融入普通抽屉网格，统一参与「自定义 / 按类型 / 首字母」排列、拖拽排序与交互；保留原有路径、固定状态与原文件保护语义。
- **Dock / 抽屉右键菜单新增「关闭」**：仅对正在运行且存在可关闭窗口的单个应用显示「关闭」，通过标准 Windows `WM_CLOSE` 消息优雅关闭窗口（支持多窗口、UWP 窗口及固定/未固定图标），并即时同步 Dock 运行指示点，不取消固定、不删除快捷方式、不误关其他程序。
- **缺失目标快捷方式图标兜底**：当保留的快捷方式目标文件在磁盘上已缺失时，`StockIcon` 按扩展名回退标准系统图标，避免抽屉显示模糊灰色占位块或导致 Genie 预烘焙缓存反复失效；文件恢复后自动刷新真实图标。

## 1.9.8

- **真实桌面双向镜像**：抽屉直接映射 Windows 真实桌面，支持将文件拖放到抽屉内的 `.exe`、脚本或快捷方式上带参启动，支持拖入文件夹移动/复制、跨窗口拖出至外部应用、`F2` 重命名、复制删除、`Alt+双击` / `Alt+Enter` 打开属性页及实时文件同步。
- **右键菜单优化**：菜单构建使用常规外壳标志并临时锁定标准箭头指针，消除弹出瞬间的系统忙碌转圈，菜单关闭或进程退出时立即还原系统光标。
- **图标加载与快照缓存**：刷新桌面或壳层变动期间保留上一次有效图标快照，过滤全透明空图标并增加多尺寸/StockIcon 回退与短暂自动重试。
- **图标打开方式切换**：设置中新增「图标打开方式（单击打开 / 双击打开）」，默认保持单击打开，四窗格按钮与拖拽排序不受影响。
- **桌面常驻与按键屏蔽**：空桌面状态下 Dock 自动常驻，存在最大化或全屏窗口时平滑隐藏并保留底部唤醒条；新增按住自定义按键（如 `~`）立即收起 Dock 并拦截唤醒，松开自动恢复。
- **快速开机自启动**：开启开机自启动优先注册当前用户级 `AtLogOn` 登录计划任务并清理旧 `HKCU\...\Run` 项，异常时自动降级回写注册表兜底。

## 1.9.7

- 减少启动时的无效快捷方式解析，将独立桌面读取与窗口创建并行；保持扫描完成后再校准及保存布局。
- 使用标准 ReadyToRun 发布预编译，优先预热 Dock 固定图标，改善应用自身启动及首次抽屉就绪时间。
- 将设置文案简化为“开机自启动”，保留原有用户级 Run 启动方式和开关行为。
- 本轮未进行整机重启计时，不声称改变 Windows 对登录启动项的调度等待。

## 1.9.6

- 优化抽屉四角的像素覆盖精度，改善纯黑及高对比度背景下圆弧的细小阶梯和方向不一致问题。
- 仅为四个圆角生成可复用的局部覆盖贴片，按实际 DPI 和 Genie 前景缓存分辨率匹配采样；保持原有圆角半径、面板尺寸、实时玻璃、材质透明度与动态阴影。
- 保留原有 Genie 展开、收起及中途反向，未修改布局、快捷键、桌面文件操作或配置保存规则。

## 1.9.5

- 修复抽屉圆角被重复裁剪导致边缘 Alpha 覆盖过硬的问题；保持原圆角尺寸、实时玻璃、Genie 形变及动态阴影。
- 修复仅悬停高亮、没有显式选择时，文件快捷键没有操作目标的问题。显式多选仍优先；搜索框中的文本编辑不会操作文件。永久删除继续使用 Windows Shell 确认流程。
- 加强布局保护：检测启动宿主导致的私有 AppData 重定向，避免启用另一份布局；配置写入后读回核验，布局历史只记录已提交的写入。
- 用户配置和自定义顺序继续保留，不重新执行首次安装默认布局。

## 1.9.4

- 修复 Genie 抽屉动画中阴影停留在最终矩形位置的问题。阴影现在随当前漏斗轮廓展开、收缩，并支持中途反向与连续操作。
- 保留 1.9.3 本地版采用的 GPU 高斯轮廓投影，避免恢复高成本的整面动态模糊；阴影与前景共用动画渲染场景，兼顾冷态流畅度和原有玻璃、圆角及阴影质感。
- 对动画反向、外部点击、拖拽固定和拖拽后滚动进行了针对性回归。短冷态对照未发现明确、可重复的性能退步；仍有一次归因未定的系统呈现长帧，不承诺消除所有环境下的偶发卡顿。
- 包含此前已完成的简体中文/英文安装、覆盖升级和卸载支持；现有配置保持不变。1.9.3 仅作本地验证，未单独公开发布。
- 安全说明：1.9.2 历史 Defender 告警的微软复核仍为 Pending。1.9.4 在开发机的 Defender 与 ClamAV 定向检查中未检出；这不代表其他设备或云端检测必然放行。应用和安装器尚无 Authenticode 代码签名；更新清单签名不替代代码签名。

## 1.9.2

- 安装、覆盖升级和卸载支持简体中文与英文。安装程序按 Windows 界面语言推荐选项，可在启动时切换。

## 1.9.1

- 静止指针唤醒 Dock 时，图标先按正常尺寸展开。主动移动后即可接上波浪放大。
- 抽屉支持键盘定位、多选和 Windows 文件快捷键。按 `F6` 在抽屉和 Dock 间切换。Dock 的删除快捷键只取消固定。
- 托盘和设置的手动更新检查会显示进度、检查结果及后续操作。自动检查保留安静提醒方式。

## 1.9.0

- 首次启动按当前 Explorer 桌面的列顺序初始化抽屉，并固定可用的 Windows 系统入口。
- 支持当前用户安装、覆盖升级与卸载，保留配置。
- 支持基于签名清单的正式版本更新，用户确认后启动安装。
- 默认每天检查一次更新，可在设置中关闭。托盘与设置同步显示可用版本。
- 托盘简化为设置、检查更新和退出。设置支持独立保存布局与导出本地诊断。
- 改善工作区变化后的显示布局恢复，保留 1.8.9 的玻璃和动画。
