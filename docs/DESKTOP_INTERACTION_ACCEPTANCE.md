## 帧时间与桌面证据

- 两轮交替的快速滚轮对照。WPF CompositionTarget.Rendering 回调间隔 P95 从 25.84–27.47ms 降至 7.01–7.14ms，P99 从 30.25–30.37ms 降至 15.24–16.83ms，最大值从 31.03–45.82ms 降至 20.73–38.18ms。超过 12.2ms 的回调间隔由每轮 67–69 次降至 3–4 次。末次带录制复测为 P95 6.94ms、P99 7.37ms、最大 24.39ms。
- 两份 DXGI 桌面录制，在共同 1.75–2.70 秒的滚动区段按同一图标区域亮度变化筛帧。可见变化 44→69 帧，变化间隔 P50 24→12ms、P95 31→19ms、P99 60→19ms。录制有采集开销，帧时间采用录制时间戳。ETW 丢失事件，无法给出面板逐帧扫描或独立 Present 统计。
- Genie 内部执行均值 0.23→0.23ms，抽屉展开 WPF P95 11.14→9.17ms，最大 22.89→14.28ms，收起 P95 6.83→7.20ms。Dock 展开 WPF P95 9.41→10.75ms，P99 28.10→20.69ms，最大 46.35→32.64ms。收起 P95 10.75→11.62ms，P99 24.86→13.52ms。
- 本地证据位于 test-results/199-takeover-paired-*、199-takeover-final-*、199-takeover-accept-*、199-takeover-screen-base-*。其中 drawer-scroll.json、drawer-bottom.png、desktop-duplication.mkv、desktop-motion-analysis.json、drag-e2e-result.json 及 ext-drop-pin-result.json 分别保留原始间隔、实机截图、录制与文件操作结果。
- 最终定位及菜单回归位于 test-results/199-takeover-closeout-*。该轮滚轮回调 P95 6.85ms、P99 8.41ms、最大 24.12ms。
- 隔离排序复测见 test-results/199-takeover-anchor-final-*。同一批临时文件在接管基线和最终实现上跑通跨行、反向、取消、重开及磁盘读取，实际用户配置独立确认字节不变。
- 早期继承的测试还向桌面写了截图，覆盖了一张先前测试图。已恢复上轮同一测试时保存的历史截图副本，清理本轮额外生成的截图。测试现只把截图写入验收目录。

今后修改抽屉状态、焦点或文件操作时，优先跑 P0，随后选择对应的 P1。每项包含完成、取消、失焦与再进入，相关文件操作核对真实结果和源文件。通过范围以证据为准。
